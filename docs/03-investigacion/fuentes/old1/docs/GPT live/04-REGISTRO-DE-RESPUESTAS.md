# Registro de respuestas durante Live

ChatGPT Live debe mantener internamente una ficha por cada respuesta relevante.

## Ficha

- Tema y pregunta: `Tnn-Qnn`.
- Estado: resuelto, parcial, aplazado o sin tratar.
- Clasificación: decisión, caso real, regla, dato, excepción, hipótesis, contradicción o pendiente.
- Respuesta fiel de Víctor.
- Ejemplo real asociado.
- Condición que dispara el hecho.
- Pasos que ocurrieron.
- Resultado normal.
- Resultado raro o fallo.
- Datos mencionados.
- Personas, plataformas y canales implicados.
- Números, horarios, importes o límites exactos.
- Conflicto con el contexto actual, si existe.
- Pregunta de seguimiento que todavía falta.

## Normas

- Una respuesta puede cubrir varias fichas.
- No completar campos con inferencias.
- Conservar las palabras exactas de Víctor cuando un término o ejemplo sea decisivo.
- Si cambia de opinión, conservar ambas versiones y marcar cuál es la más reciente.
- Si una respuesta contiene una solución técnica, separar el problema de la solución propuesta.
- No mostrar todo el registro después de cada respuesta; usarlo para los resúmenes periódicos y el informe final.
