# Entrevistas de SANIA con ChatGPT Live

Esta carpeta permite continuar las entrevistas de requisitos sin acceso al repositorio.

## Qué archivo usar

Adjunta únicamente `PAQUETE-COMPLETO-PARA-CHATGPT-LIVE.md` a la conversación de ChatGPT Live. Los demás archivos sirven para mantener y auditar el paquete, pero no hace falta subirlos.

## Cómo empezar

Después de adjuntar el paquete, escribe o di:

> Lee el archivo entero. Sigue sus instrucciones y empieza la entrevista por el primer tema prioritario que siga pendiente. Hazme una sola pregunta cada vez.

Responde con naturalidad. Puedes contar varios hechos a la vez: el entrevistador deberá registrarlos y continuar por el siguiente hueco, sin obligarte a repetirlos.

## Cómo terminar una sesión

Cuando quieras devolver el trabajo a Codex, di:

> Genera ahora el informe de devolución completo siguiendo exactamente el formato del paquete. No resumas ni omitas contradicciones, ejemplos reales o preguntas pendientes.

Guarda la respuesta completa como Markdown y entrégasela a Codex junto con la fecha de la sesión.

## Regla de vigencia

Este paquete refleja los planos del commit `024c8e7`. Si los planos cambian después, hay que regenerar el paquete antes de iniciar otra tanda de entrevistas.

## Contenido de mantenimiento

- `01-PROMPT-MAESTRO.md`: comportamiento del entrevistador.
- `02-CONTEXTO-ACTUAL-DE-SANIA.md`: hechos y decisiones ya conocidas.
- `03-GUION-DE-ENTREVISTA.md`: temas y preguntas pendientes.
- `04-REGISTRO-DE-RESPUESTAS.md`: clasificación interna de las respuestas.
- `05-FORMATO-DEL-INFORME.md`: informe que debe volver a Codex.
- `06-CHECKLIST-DE-CIERRE.md`: control previo a la devolución.
- `MANIFIESTO.md`: versión y cobertura.
- `referencia/`: copias estructuradas de los planos de origen.
