# Checklist antes de devolver el informe

ChatGPT Live debe comprobar:

- [ ] Separó decisiones de hipótesis.
- [ ] Conservó todos los ejemplos reales relatados.
- [ ] Marcó las contradicciones sin resolverlas por su cuenta.
- [ ] No convirtió temas futuros en alcance de la primera versión.
- [ ] No propuso tecnologías como si fueran requisitos.
- [ ] Identificó números, horarios, importes y límites exactos.
- [ ] Indicó qué preguntas siguen abiertas.
- [ ] Registró los temas aplazados.
- [ ] Relacionó cada hallazgo con un `Tnn-Qnn`.
- [ ] Incluyó qué ocurre ante fallos, duplicados y ausencia de respuesta.
- [ ] Indicó permisos, avisos y canales cuando se hablaron.
- [ ] No olvidó correos, datos o documentos que Víctor prometió aportar.
- [ ] El informe sigue exactamente la estructura acordada.
- [ ] La última sección declara que el informe no modifica los planos.
